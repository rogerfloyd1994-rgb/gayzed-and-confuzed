MOTION ORGANIZER — START HERE

Choose ONE version:

GET THE FILES
On this PC, open Desktop > Appimade. If you received the files as a ZIP,
right-click the ZIP and choose "Extract All" before installing. Choose the
installer for your device from the folders below; "04 - Website" is for
publishing a website, not installing the app.

WINDOWS DESKTOP (simplest on a Windows PC)
1. Open "01 - Windows".
2. Double-click "Motion Organizer Windows Setup.exe".
3. Follow the installer. Open Motion Organizer from the Start menu when it
   finishes.
The installer is not code-signed. If Windows blocks it, cancel and do not turn
off Smart App Control or Defender. Ask for help if you are unsure.

ANDROID (test version)
1. Send "02 - Android\Motion Organizer Android.apk" to your Android device.
2. Open the APK on the device and follow Android's prompts.
Android may ask you to allow installs from the app you used to open the APK.
Only allow this if you trust the file; turn the permission off afterward.
This is a test build, not a Google Play release.

BROWSER (Windows, macOS, or Linux)
1. Install Node.js LTS from https://nodejs.org/ if it is not already installed.
2. Open "03 - Browser App" and double-click "start-windows.cmd".
3. Use the browser page that opens. Keep the command window open while using
   the app; close it to stop the app.
In Edge or Chrome, use the browser's "Install app" menu to add it to your
device. Camera access works at the local address the app opens.

WHICH FOLDER IS WHICH?
- "01 - Windows": Windows desktop installer.
- "02 - Android": Android test installer.
- "03 - Browser App": files for running the browser version locally.
- "04 - Website": publishable website files; this is not an installer.
- "My Report Backups": your private report backup, not an app installer.

MAC
There is no Mac installer in this folder yet. A Mac computer is required to
build a .dmg. See the "macOS disk image" section in the project's README, or
run the "Build macOS DMG" workflow from the project's GitHub Actions tab.

PRIVACY
Video analysis and clips stay on your device. Report backups are not encrypted;
keep them private. Backups contain report details, not video clips. There is
no automatic cloud sync. The app does not identify faces, classify sounds, or
send remote push alerts.
